🧪 Test Enhanced Chatbot Features

📋 Instrucciones de Testing

Para testear Quick Replies y Product Cards:

  1. Abre el chatbot embebido en la sección de abajo
  2. Envía los mensajes de prueba que se sugieren
  3. Observa las respuestas mejoradas con botones y tarjetas
  4. Verifica que las funcionalidades funcionen correctamente

🎯 Mensajes de Prueba

💬 Para activar Quick Replies:

  • "Hola" - Debería mostrar botones de saludo
  • "Necesito ayuda" - Debería mostrar opciones de ayuda
  • "¿Qué productos tienen?" - Debería mostrar categorías
  • "¿Cuánto cuesta?" - Debería mostrar opciones de precios

🛍️ Para activar Product Cards:

  • "Quiero comprar vitaminas" - Debería mostrar tarjetas de productos
  • "Muéstrame productos de wellness" - Debería mostrar carousel
  • "¿Tienen suplementos?" - Debería mostrar productos relacionados
  • "Catálogo de productos" - Debería mostrar múltiples productos
